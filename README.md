# AI ChatGPT Clone 🚀

A modern full-stack AI chatbot application inspired by ChatGPT, built using React, Firebase, Node.js, Express, MongoDB, and Gemini AI.

This project was developed to strengthen my full-stack development fundamentals while learning how real AI-powered SaaS applications work.

---

## ✨ Features

- 🔐 Firebase Authentication
  - Email & Password Login
  - Google Sign-In

- 💬 AI Chat System
  - Real-time AI responses
  - Context-aware conversations
  - Continuous chat memory

- 🧠 Multi-AI Provider Architecture
  - Gemini AI
  - Groq Fallback Support
  - OpenRouter Support

- 📁 File Upload UI
- 🎤 Voice Input UI
- 🗂 Chat History Management
- 🗑 Delete Chats
- 👤 Profile Page
- ⚙ Settings Page
- 🌙 Modern SaaS UI
- 📱 Responsive Design
